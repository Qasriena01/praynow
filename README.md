# PrayNow 🕌

**PrayNow** is a Flutter mobile application designed to help Muslims manage their daily prayers and Islamic practices, especially while travelling.

## About the Project

PrayNow brings together essential prayer tools and Islamic resources in one mobile application. It aims to make it more convenient for users to access prayer-related information and maintain their religious routines while on the move.

## Features

- **Prayer Times** — Access daily prayer time information.
- **Qibla Direction** — Find the direction of the Qibla.
- **Travel Prayer Guide** — Access guidance related to prayers while travelling.
- **Adhan Notifications** — Prayer reminders and Adhan audio support.
- **Qur'an** — Access Surah-related content.
- **Hadith** — Explore Islamic hadith content.
- **Dua & Azkar** — Access daily supplications and remembrance.
- **Hijri Calendar** — View Islamic calendar information.
- **Mosque Finder** — Locate mosques.
- **Tasbih / Dhikr Counter** — Keep track of dhikr.
- **Names of Allah** — Explore the 99 Names of Allah.
- **Notes & Bookmarks** — Save useful content for later.
- **User Authentication** — Sign-in and onboarding functionality.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Required Firebase configuration for the project

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Qasriena01/praynow.git
   ```

2. Navigate to the project directory:

   ```bash
   cd praynow
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure the required Firebase settings and other environment variables according to the project setup.

5. Run the application:

   ```bash
   flutter run
   ```
